# フレキ 発注用データ（JLC FPC）

対象: `flex_100mm.kicad_pcb`（長さ100mmの参照版。長さ違いは
`split/tools/build_flex.py [長さmm]` で生成してから同じ手順で出す）

## データ

- `gerber/` 一式＋ `flex_gerber.zip`（5ファイル）
  - F.Cu（指＋配線は全てこの面）、カバーレイ開口 = F.Mask、
    外形 = Edge.Cuts
  - 補強板: `flex_100mm-pib_0.1.gbr`（PI補強板・裏面・0.1mm 指定の
    JLC 命名。両端とも先端から 2.85mm の全幅ゾーン）
  - B.Cu／B.Mask はなし（裏面は銅なし・カバーレイなしの片面構成）
  - ドリルなし（穴・ビアなし）

## 発注時指定（JLC FPC）

- 基材: フレキシブル（ポリイミド）、**1層**（指・配線は表面のみ）
- FPC厚さ: 0.11mm（嵌合部合計 0.2±0.03 を補強板で合わせる前提）
- 表面処理: ENIG（JLC FPC 標準。接点はカタログ指定で金メッキ）
- カバーレイ色: 黄（標準。黒／白は追加料金）、カバーレイは表面のみ
- 金端子（Gold Fingers）: Yes、厚み 0.2mm
- 補強板: ポリイミド、裏面、両端 2.85mm ゾーン。
  厚みは発注フォームの計算が正。データは 0.1mm（pib_0.1）で用意済み。
  フォームで別の厚みになったらファイル名を合わせて zip を作り直す
- 挿入向き: 指の面が基板側、補強板の面がアクチュエータ側

## DRC（2026-11-16 実施、KiCad 8.0.9、ルールは基板ファイル内蔵値と
.kicad_pro に設定済み）

- 違反 160件は全て設計どおりの分類:
  - solder_mask_bridge 62件 = カバーレイ窓が指フィールド全体を
    1枚の開口で開ける構造（FPC の標準構成。カタログ図面どおり
    窓端は1直線）
  - copper_edge_clearance 34件 = 深い列の指先端が基板端に接する
    32件＋チェックマークが側端に近い2件
  - track_dangling 64件 = 指先端の開放端62件＋ダミー ch31 の
    内側端2件
- 未接続 2件 = GND 3本（ch2/24/27）がフレキ内では独立導体で、
  基板側で共通化される設計のための見かけ上のもの
- クリアランス／ショート／交差は 0件
- 幾何監査: 深い列スパン 9.0（C）・先端は基板端／浅い列スパン
  8.4（B）・先端 0.85 下げ、指の銅端 2.25・窓端 2.1、補強板 2.85、
  全ネット端間導通、B.Cu に銅なし — カタログ値と一致を確認済み

## 初回実物での確認（発注前に潰せない分）

1. **ピン1の向き**: 2026-11-16 に解決済み（承認図＋公式3Dモデル
   実測＋独立トレースで、組み立て時に ch c ⇔ ch c を確認。
   対策は Zero 側基板の鏡像化で実施済み、フレキは無変更）。
   初回実物では導通確認を最終確認として行う
2. **嵌合の向きとロックの効き**: 補強板がアクチュエータ側に
   来ていること、合計厚 0.2±0.03 に収まること

## 再出力手順

```
source ~/workspace/tools-cache/kicad8-local/env.sh
cd split/flex
mkdir -p gerber
kicad-cli pcb export gerbers --output gerber \
  --layers F.Cu,F.Mask,Edge.Cuts,User.1 flex_100mm.kicad_pcb
mv gerber/flex_100mm-User_1.gbr gerber/flex_100mm-pib_0.1.gbr
cd gerber && zip ../flex_gerber.zip *
```
