# フレキ 発注用データ（JLC FPC）

対象: `flex_100mm.kicad_pcb`（長さ100mmの参照版。長さ違いは
`split/tools/build_flex.py [長さmm]` で生成してから同じ手順で出す）

## データ

- `gerber/` 一式＋ `flex_gerber.zip`（7ファイル）
  - F.Cu／B.Cu、カバーレイ開口 = F.Mask／B.Mask、外形 = Edge.Cuts
  - 補強板: `flex_100mm-pib_0.1.gbr`（PI補強板・裏面・0.1mm 指定の
    JLC 命名。両端とも先端から 2.85mm の全幅ゾーン）
  - ドリルなし（穴・ビアなし）

## 発注時指定（JLC FPC）

- 基材: フレキシブル（ポリイミド）、2層
- FPC厚さ: 0.11mm（嵌合部合計 0.2±0.03 を補強板で合わせる前提）
- 表面処理: ENIG（JLC FPC 標準。接点はカタログ指定で金メッキ）
- カバーレイ色: 黄（標準。黒／白は追加料金）
- 金端子（Gold Fingers）: Yes、厚み 0.2mm
- 補強板: ポリイミド、裏面（B面）、両端 2.85mm ゾーン。
  厚みは発注フォームの計算が正。データは 0.1mm（pib_0.1）で用意済み。
  フォームで別の厚みになったらファイル名を合わせて zip を作り直す

## DRC（2026-11-16 実施、KiCad 8.0.9、ルールは .kicad_pro に設定済み）

- 違反 124件は全て設計どおりの分類:
  - copper_edge_clearance 62件 = 両端の指先端が基板端に接する（FPC の構造）
  - track_dangling 62件 = 同じく指先端の開放端
- 未接続 2件 = GND 3本（ch2/24/27）がフレキ内では独立導体で、
  基板側で共通化される設計のための見かけ上のもの
- クリアランス／ショート／交差は 0件
- 幾何監査: 奇数行スパン 9.0（C）／偶数行 8.4（B）、露出長 奇数 2.25／
  偶数 1.75、補強板 2.85、全ネット端間導通 — カタログ値と一致を確認済み
- 生成スクリプトと基板ファイルの一致も再生成で確認済み

## 初回実物での確認（発注前に潰せない分）

1. **補強板の面**: カタログ構成図（両面FPCの積層で補強フィルムは
   片面のみ・合計197µm）から B面と仮定した。実コネクタとの嵌合で
   逆と分かったら pit_ 側で出し直す
2. **露出長と面の対応**（奇数=B面=2.25 が正か）: `build_flex.py` の
   END_B_FLIP で端Bの面入替可
3. **ピン1の向き**: 初回実物で導通確認。逆なら基板は触らず、
   フレキ側の指の並び反転で吸収する
4. ミスアライメントチェックマーク（カタログ参考形状 0.5×1.25）は
   未実装（参考形状のため機能影響なし）

## 再出力手順

```
source ~/workspace/tools-cache/kicad8-local/env.sh
cd split/flex
kicad-cli pcb export gerbers --output gerber \
  --layers F.Cu,B.Cu,F.Mask,B.Mask,Edge.Cuts flex_100mm.kicad_pcb
# 補強板は両端の矩形（0–2.85 / L-2.85–L、全幅）を1レイヤにまとめて
# 出力し、flex_100mm-pib_0.1.gbr にリネーム（厚みは発注フォーム優先）
cd gerber && zip ../flex_gerber.zip *
```
