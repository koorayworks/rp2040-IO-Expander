## 仕様（v2、2026-11-16 カタログ再精査で確定）

- 両端とも FH35C-31S-0.3SHW 用の指。ヒロセ推奨 FPC 寸法
  （原典 `split/ref/fh35c_catalog.pdf` p.5）: 全幅 F=9.6、接点スパン
  C=9.0（奇数 ch・16本）／B=8.4（偶数 ch・15本）、ピッチ 0.3、
  指幅 0.2、補強板は先端から 2.85、嵌合部合計厚 0.2±0.03
- **指は全部片面（F.Cu）に二段千鳥**。深い列 = 奇数 ch（先端は
  基板端まで）、浅い列 = 偶数 ch（先端は端から 0.85 下がる）。
  裏面は嵌合部に銅なしで、補強板は裏面（＝アクチュエータ側）。
  根拠: カタログ p.6 の積層構成図（片面FPC構成が正規の選択肢で、
  両面構成でも嵌合部の裏面銅箔は除去することと注記）＋ p.5 平面図
  （裏面側の形状は破線＝カバーレイ／補強板の端のみ）＋ p.1 挿入写真
  （指は片面だけに見える）。**v1 の「奇数=B.Cu／偶数=F.Cu の両面
  分割」は誤りだったため廃止**
- 露出長: 深い列 2.1／浅い列 1.25（カバーレイ窓端は先端から 2.1、
  指の銅は 2.25 まで。カタログの 2.1±0.1 と参考寸法 (1.25) に対応）
- 配線は全て F.Cu 直通（ビアなし）、幅 0.15。B.Cu は銅なし
  ＝ 発注は片面（1層）FPC
- チャンネル割当は `split/FFC_PINMAP_30P.md`。コンタクト31はダミー
  （指のみ、配線なし）
- ミスアライメントチェックマーク（カタログ参考形状 0.5×1.25）:
  両端とも ch1 の銅の膨らみとして近似実装（先端から 1.25–1.75、
  左端寄り。参考形状のため近似で可とした）
- 補強板ゾーンは User.1 に両端分を図形で注記。発注用は
  `gerber/flex_100mm-pib_0.1.gbr`（PI補強板・裏面・両端 2.85mm）
