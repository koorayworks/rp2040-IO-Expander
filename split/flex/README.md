# FH35C フレキ（Zero 側 ⇔ モジュール側）

生成スクリプト: `split/tools/build_flex.py [長さmm] [出力先]`
v1 生成済み: `flex_100mm.kicad_pcb`（参照用の標準長さ）

## 仕様（2026-11-11 確定分）

- 両端とも FH35C-31S-0.3SHW 用の指。ヒロセ推奨 FPC 寸法
  （原典 `split/ref/fh35c_catalog.pdf` p.5）: 全幅 F=9.6、接点スパン
  C=9.0（奇数 ch・16本）／B=8.4（偶数 ch・15本）、ピッチ 0.3、
  指幅 0.2、補強板は先端から 2.85、mating 部合計厚 0.2±0.03
- チャンネル割当は `split/FFC_PINMAP_30P.md`。コンタクト31はダミー
  （指のみ、配線なし）
- 奇数 ch は B.Cu、偶数 ch は F.Cu を直通（ビアなし）。配線幅 0.15
- 露出長: 奇数 2.25／偶数 1.75（カタログの二段千鳥）
- 補強板ゾーンは User.1（A端）／User.2（B端）に図形で注記。
  発注時は JLC の PI 補強板指定（レイヤ命名 pit_*/pib_*）へ変換する

## 未確認（初回実物で潰す）

- 露出長と面の対応（奇数=裏面・長いの組み合わせが正か、カタログ図面と
  実コネクタで突き合わせ）。スクリプトの END_B_FLIP で端Bの面入替可
- コネクタ実装面の組み合わせ（Zero 側 J3/J4 とモジュール側の向き）で
  フレキの表裏が決まる。実物で導通確認してから量産長さを決める
- 長さは搭載先ごとに確定（推奨150mm以下）。reNera はトレイ内蔵のため
  短め想定
- ミスアライメントチェックマーク（0.5×1.25 参考形状）は v1 未実装
- 電源 ch（VSYS/GND/3V3）の配線幅拡大は v2 候補（v1 は全 0.15）
