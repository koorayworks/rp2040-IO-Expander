# モジュール側基板 ピン・ネット凍結表

2026-11-11 凍結。根拠: 本人決定「モジュール側に RP2040 は載せない」、
MDBT50Q 割当は REV.A の `ext_board/PINMAP_EXT.md` を踏襲（多重化なし）、
電源は REV.B（`REV_B_SPEC.md` / `ext_board_revb/README_REVB.md`）を移植、
フレキ接続は `split/FFC_PINMAP_30P.md` が正本。

## 前提

- メイン MCU は MDBT50Q-1MV2（nRF52840）のみ。RP2040・フラッシュは載せない
- 基板外形 **18×36mm**、四隅に M2 ネジ穴（Ø2.2 NPTH、端から中心 2.5mm）
  目標の 34mm では下端の帯（四隅の穴＋JST の THT ピン＋昇圧/mux 群）が
  物理的に閉じなかったため、上限の 36mm を使う（2026-11-11 配置設計で確定）
- MDBT50Q は基板端（アンテナ端）に配置しキープアウト確保。電源部はアンテナと
  反対側の端に寄せる（REV.B の「スイッチング部をアンテナから遠ざける」を踏襲）
- 内蔵 DC-DC は使わない（VDD と VDDH を同一 3V3 に直結する内部 LDO モード。
  DCCH = NC、ファーム側でも DC-DC を有効化しないこと）
- 32.768kHz 水晶は載せない（XL1/XL2 = NC、内部発振で運用）

## 電源（REV.B 移植）

```
電池（乾電池系 1〜3.3V、ケース側）
  │ J_BAT = JST PH 2P、**THT トップエントリー B2B-PH-K**（配置設計で確定:
  │         SMD サイドエントリー S2B-PH-SM4-TB はパッド占有 8.2×9.2mm が
  │         下端の帯に入らなかった）。pin1 (基板座標 x=6.6) = BAT+、pin2 = GND
  ▼ pin1 = BAT+
SW_PWR = PCM12SMTR（C&K、電池ライン直列。pin2 = コモン = VBAT 側、pin3 = BAT+、pin1 = NC。
  2026-11-14 に CAS-120A から変更: 定格 100mA では昇圧入力の想定最大 ~156mA に不足のため 0.3A 品へ）
  ▼ VBAT
  ├─► U3 TPS610994DRVR 昇圧 ── 3V3_BAT
  │     WSON-6、FB = GND（3.3V 固定品）、EN = VBAT 直結
  │     L1 = 2.2µH 2520 シールド型、CIN/COUT = 10µF 0603
  └─► R11 1M / R12 1M 分圧（ネット VBAT_SENSE）─► MDBT50Q pin12
        (P0.31 / AIN7)（電池電圧の ADC 監視。2026-11-13 に直結から変更）
        分圧比 1/2: 乾電池2セル新品 約3.4V → 約1.7V で SAADC 仕様内。
        直結時は絶対最大定格（VDD+0.3V）は超えないが入力 > VDD で飽和する
        ため分圧化した。分圧電流は約1.7µA（VBAT はスイッチ後段）。
        ファーム注意: ソース抵抗 500k のため SAADC のアクイジション時間を
        長く取ること。sekigon の non-lipo battery management を使う前提で、
        読み値の換算は分圧比 1/2 を反映すること

フレキ ch1 VSYS (USB 5V)
  ├─► MDBT50Q pin32 (VBUS)
  └─► U2 TPS7A2033PDBVR LDO ── 3V3_USB（入出力 10µF 0603）

U4 TPS2116DRLR (priority mode, MODE = VIN1)
  VIN1 = 3V3_USB（優先）、VIN2 = 3V3_BAT、VOUT = 3V3
  PR1 分圧 R4 = 180k（上）/ R5 = 100k（下）で切替点 VIN1 ≈ 2.8V
  ▼ 3V3
  MDBT50Q pin28 (VDD)・pin30 (VDDH)、フレキ ch3、FFC#1/#2 等の全負荷
```

- LiPo / LFP は対象外（接続禁止をシルク・説明書に明記）。充電回路は載せない
- TPS2116 の入力デカップリング 0.1µF は REV.B では配置余地がなく未実装だった。
  モジュール側では U4 直近に置く

## FFC#1（トラックボール、sekigon 式 6P、FH12-6S-0.5SH）

| pin | 接続 |
|---:|---|
| 1 | 3V3_TB（センサー電源ゲート経由） |
| 2 | TB2 (CS) |
| 3 | TB3 (MOTION) |
| 4 | TB4 (SDIO) |
| 5 | TB5 (SCLK) |
| 6 | GND |
| MP | GND |

- センサー電源ゲート: 3V3 → ロードスイッチ → 3V3_TB、制御は TB1 (P1.04)。
  REV.B では面積不足で見送ったが、モジュール側では実装する（推奨事項）。
  配置設計で確定: **AO3401 相当の P-ch MOS（SOT-23、1=G/2=S/3=D）＋
  ゲートプルアップ 100k** の最小構成。TB1 を Low にすると ON（アクティブ Low）

## 配置メモ（2026-11-11、build_module.py / module_board.kicad_pcb）

- 表面: MDBT50Q（アンテナは上端）、SWD パッド、FH35C（表面分）、
  LDO (U2)＋入出力コンデンサ、PR1 分圧 (R4/R5)、センサー電源ゲート
  (Q1/R6)、I2C プルアップ (JP1–JP4／R7–R10)、JST PH
- 裏面: FH35C（裏面分）、FFC#1/#2、はんだジャンパ SJ1/3/4/6、
  昇圧 (U3/L1/C4)、mux (U4)、電源スイッチ SW3 (PCM12SMTR)、MDBT デカップリング
- 電源スイッチは下端の帯に穴のない置き場がなく、**裏面・左端**
  （MDBT の横）に配置した。基板の端から操作する前提
- 昇圧出力コンデンサ C5 と mux 入力コンデンサ C6 は裏面の帯が満杯のため
  表面に置いた（レールはビアで表裏を渡る）
- 配置段階の DRC はエラー系 0（残りは未配線と見た目項目のみ）

## FFC#2（拡張 6P、FH12-6S-0.5SH、はんだジャンパ切替式）

- REV.A の仕様（`ext_board/PINMAP_EXT.md` の FFC#2 表）をそのまま踏襲する。
  デフォルト = 統一モード、切替後 = TPS43 モード。切替表は基板シルクにも印刷
- 実装注意（2026-11-12 訂正）: SJ3／SJ4 は電源ネットが切替側（TPS43 側）に
  あるため、生成スクリプトでデフォルト／切替を取り違えた初版があった。
  正しくはデフォルト側パッド = EX3／EX4（西）、切替側 = GND／3V3（東）で、
  SJ3 の GND 引き出し（スタブ＋ビア）は東パッド（13.9, 30.6）から取る

## I2C プルアップ（2026-11-12 追加、ジャンパー選択式）

Cirque 等の I2C ポインティングデバイス用に、信号線へ 4.7k（0603）プルアップを
はんだジャンパー経由で接続できるようにした。構成は
信号 ─[JP]─ PU_xx ─[4.7k]─ レール。

| ジャンパー | 信号 | 抵抗 | レール | デフォルト |
|---|---|---|---|---|
| JP1 | TB4 (FFC#1 pin4) | R7 | 3V3_TB | OFF（ネックなし） |
| JP2 | TB5 (FFC#1 pin5) | R8 | 3V3_TB | OFF（ネックなし） |
| JP3 | EX2 (FFC#2 pin2, SDA) | R9 | 3V3 | ON（ネック接続） |
| JP4 | EX5 (FFC#2 pin5, SCL) | R10 | 3V3 | ON（ネック接続） |

- FFC#1 側はトラックボール（SPI）使用時にプルアップ不要なためデフォルト OFF、
  I2C デバイスを使うときだけブリッジする。FFC#2 側は I2C 前提のためデフォルト ON

## その他

- SWD パッド（4つ、1.27mm ピッチ）: 3V3 / SWDIO / SWDCLK / GND
- ボタン／LED: モジュール側には置かない（2026-11-11 削除決定）。BOOT／RESET／
  STATUS_LED はフレキ経由で Zero 側のボタン・LED がそのまま効く
- ネジ穴: 四隅 Ø2.2 NPTH。アンテナ側の2穴は MDBT50Q のアンテナキープアウト
  外に置く（SPLIT_SPEC.md のモジュール側基板の節が正）
