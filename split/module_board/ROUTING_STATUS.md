# モジュール側基板 配線ステータス（2026-11-12）

## 現在の基板（module_board.kicad_pcb）

ラウンド16の配線結果。ビアは外径0.40mm／ドリル0.20mm級を併用
（ネットクラス 0.40/0.20、最小ビア径ルール 0.40）。

最終DRC（.kicad_pro 再適用後）:

- clearance 0、hole 系 0
- shorting は意図的ジョイントのみ（下記6件すべて接続を実地確認済み:
  DRC掲載3件＋形状確認3件）
- **未接続 3ペア**:
  - GPIO0: J2.23 パッド単独（J1＋U1 側は接続済み）
  - GPIO3: J2 スタブ単独（J1＋U1 側は B ウェブで接続済み）
  - GPIO4: U1.23 パッド単独（J1＋J2＋ウェブは接続済み）
- copper_edge_clearance 26件（基板端近くの配線。受入可否は未判断）

意図的ジョイント（全6件）:

- SJ1: FFC2_1↔3V3（ネック w0.2 (9.5,30.6)-(10.4,30.6) B.Cu）
- SJ3: FFC2_3↔EX3
- SJ4: FFC2_4↔EX4（ネック w0.2 (14.7,30.6)-(15.6,30.6) B.Cu、
  EX4 スタブ (14.7,30.6)-(14.7,29.7) で到達を確認）
- SJ6: FFC2_6↔GND
- JP3: PU_EX2↔EX2（ネック w0.2 (12.3,23.8)-(13.2,23.8) F.Cu）
- JP4: PU_EX5↔EX5

## 残り3ペアの切り分け（手仕上げ・種付けとも試行済み）

- GPIO4 (U1.23): パッド北側ポケットは GPIO3/GPIO5 の先端ビアで満員。
  ラウンド17で配置ビア (8.58,15.98)＋Fスタブの種付けが効き、
  その基板では完結した（代わりに他ネットが入れ替わりで落ちた）。
- GPIO0 (J2.23): 配置ビア (6.8,20.65)＋Bスタブ2段の種付けが
  ラウンド17で完結を確認。手仕上げは GPIO14 のビア・GPIO2 の
  B斜め・下辺パッド矩形に四方を塞がれる。
- GPIO3 (J2): スタブ端 (7.8,19.3) は配置銅で四方封鎖
  （W: GPIO13 潜りビア (7.55,18.95)、E: GPIO9 ビア (8.4,18.98) と
  GPIO5 の B ウェブ、S: GPIO2 ビア (7.35,20.6) と GPIO11 ビア
  (7.85,21.15)、W追加: GND の B スタブと GPIO15 のスタブ）。
  種付け案5つ全滅。**直すなら配置変更が要る**: GPIO13 の潜りビアを
  動かしてスタブ端の扇を空けるのが本命。

## 次にやるなら（ラウンド20 の処方箋）

1. 配置は placement_v14_round17seeds（GPIO4/GPIO0 の種付け込み）を土台に、
   GPIO13 の潜りビアを移動して GPIO3 J2 の逃げを確保する
2. ビアは 0.40/0.20 のまま（ラウンド16で 5→3ペアに効いた）
3. Freerouting は配置（種付け込み placement）から一発で引く。
   配線済み基板からの一部剥がし再配線（ラウンド18/19）と
   基板間グラフト（16+17）は、取り込み時に大量のクリアランス
   違反や負荷パスの切断を起こして不採用と確定した
