# ZERO-WIRELESS EXT REV.B

RP2040-Zero 互換フットプリント延長型基板（18.0×43.5mm）の電源拡張リビジョン。
REV.A（USB 給電のみ）に対して、乾電池駆動（昇圧＋電源 mux）を追加した。
基板外形・REV.A の全フットプリント位置/回転/パッドネットは REV.A から不変
（監査: tools/audit.py、許可差分は U2.5 の 3V3→3V3_USB のみ。AUDIT PASSED）。

## 電源トポロジ

```
電池 (ケース側, 乾電池系のみ 1〜3.3V)
  │ J7 パッド (pin1 = BAT_IN, pin2 = GND)
  ▼
SW1 (CAS-120A, BAT+ 直列スイッチ) ── VBAT
  ├─► U3 TPS610994DRVR 昇圧 (L1 2.2µH, C4/C5 10µF) ── 3V3_BAT
  └─► (将来の AIN 監視用。現版は未接続。下記「ファーム側メモ」参照)

USB-C ── U2 TPS7A2033 LDO ── 3V3_USB ──┐
                                        ├─ U4 TPS2116 (priority mode) ── 3V3 ── 全負荷
3V3_BAT ────────────────────────────────┘
```

- **入力仕様: 1〜3.3V、乾電池系のみ（単セル〜2セル）。充電回路なし。
  LiPo / LFP は対象外（接続禁止）。** 電池は基板に載せずケース側から J7 へ引き込む。
- U4 TPS2116 は MODE=VIN1 の priority mode。USB 側 (3V3_USB) が生きている間は
  電池側から給電せず、LDO 側への逆流もない。切替点は PR1 分圧
  (R4=180k / R5=100k) で VIN1 ≈ 2.8V nominal（ばらつき込み 2.58〜3.02V、
  LDO 最低出力 3.267V に対して余裕あり）。
  U4 の回転は +90°（基板実値）。これはパッド列が帯の配線方向に合うためで、
  0° では VOUT/MODE の引き出しが成立しなかった。
- U3 は 3.3V 固定品 TPS610994 (WSON-6)。FB=GND で分圧抵抗なし。
  EN は VBAT 直結（フローティング禁止のため）。起動 0.9V / 動作 0.65V まで。
  インダクタは 2520 シールド型 2.2µH（Vout>3.0V の TI 推奨値）。
  CIN (C4) は配置制約で VIN パッドから約 3.4mm とやや遠い（妥協点として明記）。
- C2 (REV.A の LDO 出力コンデンサ 10µF) は配線構造上 mux の出力側 (3V3) に
  残っている。実害なしとして受容（入力側デカップリングは U4 直近の
  0.1µF 推奨だが配置余地なし。残課題参照）。

## 電池端子が JST PH でなくパッドのみ (J7) の理由

- THT 版 B2B-PH-K: ハウジングが表面側に来て MDBT50Q の缶
  （x 3.8–14.2 × y 26.3–41.8）と JLEG の表面パッドに衝突し配置不能。
- SMD 版 B2B-PH-SM4-TB / S2B-PH-SM4-TB: 配置走査の最良でも
  クリアランス実マージン 0.106mm、その位置ではハウジングが
  アンテナキープアウトに侵入して不適合。その他は全て DRC 不合格か干渉。
- よってフォールバックとして THT パッド×2（Ø1.7/ドリル Ø0.9、ピッチ 2.54mm）:
  pin1 (1.20, 28.70) = BAT_IN、pin2 (1.20, 31.24) = GND。
  電池リードを直接はんだ付け、または 2 ピンヘッダを立てる使い方を想定。

## スイッチ SW1 の ON 方向について

CAS-120A の端子割り当て: pad2 = コモン (VBAT 側)、pad1 = BAT_IN、pad3 = NC。
スライダを pad1 側へ倒したときに ON になるはずだが、**実物で導通を確認してから**
使うこと（基板シルクの ON 表示は未確定）。

## ファーム側メモ（ZMK）

- **電池電圧監視 (non-lipo)**: sekigon の
  `zmk-feature-non-lipo-battery-management` は ADC で電池の生電圧を監視し
  低電圧でシャットダウンする想定。本基板では **VBAT を AIN へ直結する配線は
  入っていない**。理由: MDBT50Q の AIN 対応ピンは全て割当済み
  （AIN0=P0.02/GP23, AIN1=P0.03/GPIO0, AIN2=P0.04/GPIO1, AIN3=P0.05/GPIO2,
  AIN4=P0.28/GP25, AIN5=P0.29/EX6, AIN6=P0.30/BOOT, AIN7=P0.31/GP24）で、
  接続すると REV.A のパッドネット凍結条件に触れるため。
  次リビジョン候補: 第1候補 GP24 = P0.31/AIN7（裏面パッドのみのピン）、
  第2候補 EX6 = P0.29/AIN5（FFC#2 の信号とトレードオフ）。
  分圧なし直結の前提: 入力上限 3.3V = VDD のため。乾電池 2 セル直列
  （最大約 3.4V・新品時）では上限を超える可能性がある点に注意し、
  採用時はモジュール側設定 (min/max) と合わせて再検討すること。
- MDBT50Q の内蔵 DC-DC は有効化しないこと（pin28 VDD と pin30 VDDH を
  同一 3V3 に直結する内部 LDO モード前提。pin31 DCCH は NC）。
- FFC のセンサー電源ロードスイッチ（EXT_POWER 相当）は本版では見送り
  （空き GPIO・面積とも不足）。
