# ZERO-WIRELESS EXT REV.A — 延長基板（RP2040-Zero 互換フットプリント＋MDBT50Q）

分割キーボードの左右間通信を無線化するための延長基板。PC との接続は従来どおり
有線 USB（本基板は nRF52840 モジュール MDBT50Q を載せ、RP2040-Zero と同じ
キャステレーション足で既存基板に差し替えられる形にしたもの）。
仕様はリポジトリの `EXTENDED_SPEC.md`（凍結仕様）に準拠する。

- 基板外形： 18.0 × 43.5 mm（本物 23.5mm ＋ 延長 20mm）、厚さ 1.6mm、4層
- 発注データ： `gerber/`（銅4層・マスク・**ペースト（ステンシル用）表裏**・
  シルク・外形・Excellon ドリル・.gbrjob）
- 配置図： `placement.png`（上面／下面。手実装・リフローの参考用）
- ピン対応： `PINMAP_EXT.md`、部品表： `ext_board_bom.csv`（本書末尾にも転記）

## 前提（重要）

- **モジュールはブートローダ書き込み済みの MDBT50Q-1MV2（チップアンテナ版）を
  購入して搭載する想定**。書き込み済み品なら SWD 書き込みなしで USB/UART
  ブートローダ経由のファーム投入を想定する。SWD パッド（J5）は保険として残置。
- 電源は USB 給電のみ（EXTENDED_SPEC どおり昇圧・電源 mux は入れていない）。
  3.3V は LDO（TPS7A2033）で VBUS から生成。VSYS パッドには 0Ω（R3）経由で
  VBUS（5V 系）を従来どおり出す。
- ファーム側注意： MDBT50Q の **DCCH ピン（pin31）は NC**。ファームは
  **内部 LDO モード前提とし、DC-DC コンバータを有効化しないこと**
  （有効化すると動かない／不安定になる）。水晶ピン（P0.00/P0.01）と
  NFC ピン（P0.09/P0.10 系）も NC 扱い（詳細は PINMAP_EXT.md）。

## 設計判断

1. **MDBT50Q フットプリントの差し替え**：既存 CORE_BOARD のモジュール図は
   実ランドパターンではない抽象図形だったため使用せず、Raytac データシート
   推奨ランドパターンと全61パッド一致を検証した形状
   （出典： GitHub `siderakb/mdbt-micro` の `MDBT50Q.kicad_mod`）を採用。
   ピン番号⇔信号の対応はリポジトリの `MDBT50Q_PINMAP.csv` とデータシートで
   全ピン照合済み。
2. **上半分は機械マスター厳密維持**：23 キャステレーションパッドの座標・
   ネット、USB-C（TYPE-C-31-M-12）位置、BOOT/RESET ボタン位置は IO_BOARD
   からそのまま複製。裏面パッド GP17〜GP25＋GND（J6）は前面パッド間の
   ギャップ位置に配置。
3. **Rev.W の欠陥是正： USB-C の CC プルダウン追加**（R1/R2 = 5.1kΩ、
   CC1/CC2 → GND）。元の IO_BOARD には無く、C-to-C ケーブルで給電されない
   問題があったため新規追加した。裏面（B.Cu）配置。
4. **層構成**：4層。In1 = GND プレーン、F/B にも GND ポア＋スティッチ。
   In2 は信号層として使用（GND プレーン1枚構成は仕様の範囲内と判断）。
5. **設計ルール**：配線 0.10mm／クリアランス 0.10mm／ビア 0.40/0.20mm
   （JLCPCB 4層の標準製造範囲内）。hole clearance は 0.20mm、最小ドリル
   0.20mm に設定（キャステレーションとスティッチビアの密度のため）。
   `copper_edge_clearance` は重大度を warning に変更（キャステレーションと
   USB-C パッドの基板端接合は設計上必須のため。警告 34 件はすべてこの種）。
6. **アンテナキープアウト**：モジュールはアンテナ端を基板下端に向けて配置。
   全層銅箔禁止エリア x 4.35〜13.65 × y 38.0〜43.5mm をルールエリアで設定。
   当初案（x 3.0〜15.0）から M2 ネジ穴コートヤードとの干渉回避のため縮小した。
   チップアンテナ素子自体は完全に覆うが、**データシート推奨幅（約12.4mm）に
   対し本基板は約9.3mm と狭い**。電波到達距離に影響しうる点に留意
   （左右間通信の近距離用途を前提に許容した判断）。
7. **裏面部品とホスト側クリアランス**：LDO・入出力コンデンサ・FFC×2・
   CC プルダウンは裏面（B.Cu）に集中配置した。**本基板を載せるホスト基板側
   には裏面部品の高さぶんのクリアランス（切り欠き等）が必要**。FFC ケーブル
   は基板下方向（+Y）に出る。FFC#1 = トラックボール（sekigon PAW3222
   モジュール規格： pin1=3V3、pin6=GND 固定、信号は CS/MOTION/SDIO/SCLK の
   4 本を TB2〜TB5 に割当て。TB1/TB6 は未使用）、FFC#2 = 拡張 GPIO
   （はんだジャンパ切替式。PINMAP_EXT.md 参照）。
8. **VSYS 接続**：R3 = 0Ω で VBUS → VSYS を接続（従来どおり 5V 系を出す）。
   USB-C シェルは GND 接続。SBU ピンは無接続。
9. **M2 ネジ穴**：下端角 2 か所（中心 (1.8,41.2) / (16.2,41.2)、NPTH ⌀2.2）。
   基板幅 18mm に対し M2 ネジ頭（約 ⌀3.8〜4）が角に少しはみ出す。片持ちの
   固定補助として割り切ること。
10. **配線手法**：第1〜2ラウンドは自作グリッド A* ルーター＋手配線
    だったが、DRC エラーが大量に残ったため、第3ラウンドで全配線を
    rip-up し Freerouting 2.5.0 で引き直した（詳細は末尾
    「第3ラウンドの配線手法」）。USB は ESD（USBLC6-2SC6）経由で
    ペアを短く配線する方針は維持。
11. **ボタン・LED 位置は公式 STEP 実測**（第2ラウンドで反映）：
    Waveshare 公式 RP2040_Zero.stp のソリッド実測に基づき、SW_BOOT 中心
    (4.51, 16.01)、SW_RESET 中心 (13.51, 16.01)、D2 LED 中心 (9.01, 15.48)
    に合わせた（フットプリント形状は従来のまま、中心のみ移動。LED 回転は
    STEP から pin1 向きが判定できないため従来維持）。実測データの控えは
    `~/workspace/rp2040-zero-step-check/step_positions.md`。
    なお移動後のボタンパッド（F.Cu、1.30×1.30mm 矩形）と JLEG
    キャステレーションの PTH パッド（2.60×1.50mm 楕円）が F.Cu 上で
    実際に重なる（x 方向に最大約 0.6mm）。第3ラウンドで形状座標から
    確認した結果、これはモデル上の誇張ではなく**実干渉**である
    （ボタン側パッド SW_BOOT (2.66,14.16)/(2.66,17.86) × JLEG pad
    27/26、SW_RESET 側も同様）。ボタン位置（STEP 実測）と JLEG
    パッド寸法（ホスト嵌合寸法）の両方が固定条件のため今ラウンドでは
    解消せず、DRC に shorting 4 件＋solder_mask_bridge 4 件が残る。
    実物ではボタン端子がパッド全面を覆う訳ではないため短絡するとは
    限らないが、次リビジョンではボタン側パッドの縮小、JLEG テールの
    短縮、またはボタン位置の再検討で解消すること。
12. **FFC#2 はんだジャンパの実装**（第2ラウンド）：SJ1/3/4/6 は B.Cu 上の
    3 パッド（0.7×0.7mm、ピッチ 0.95mm）。デフォルト側は 0.20mm のネック
    配線で事前接続（統一モード）。中間ネットは作らず、FFC パッド・中心
    パッド・デフォルト側パッドを同一ネットにしてある。切替はネックを
    カットし反対側をブリッジする。切替表は J4 脇の B.SilkS シルクと
    PINMAP_EXT.md に記載。C1/C2 はジャンパ・給電配線の都合で移動した
    （C1 → (13.40, 19.90)、C2 → (12.20, 17.85) rot-90、いずれも B.Cu）。

## DRC 結果（第3ラウンド後、2026-10-31、kicad-cli 8.0.9）

第2ラウンドの配線を全て rip-up し、クリアランスを守る Freerouting
2.5.0 で引き直した（手法の詳細は末尾「第3ラウンドの配線手法」）。

- **違反： 83 件**（第2ラウンド 697 件 → 83 件）
  - エラー系： **shorting_items 4＋solder_mask_bridge 4 の 8 件のみ**。
    全てボタン×JLEG の実干渉（設計判断 11）で、固定条件のため残置。
    clearance／tracks_crossing／hole 系は **0 件**。
  - 警告系： copper_edge_clearance 34（キャステレーション由来、
    REV.A／第2ラウンドと同数）、silk_over_copper 15、silk_overlap 15、
    silk_edge_clearance 2、text_height 9。いずれも開始点と同水準。
- **未接続： 5 件、全て GND ポア島。信号ネットの未接続は 0**
  （第2ラウンドの GND 島 7 件からも減少）。

## 第3ラウンドの配線手法（記録）

- 全配線を rip-up し、DSN エクスポート → Freerouting 2.5.0 →
  SES 取り込み（KiCad 8.0.9 の SES インポートが Freerouting 2.5 の
  出力を受け付けないため、取り込みは自前パーサ tools/r3_ses_parse.py）。
- はんだジャンパは疑似ネット方式で処理：書き出し時のみ
  SJ1L/SJ3L/SJ4L/SJ6L として FFC ピンとジャンパ中心パッドだけを
  独立ネット化し（デフォルト側へのネック配線を Freerouting が
  バイパスとして使わないため）、取り込み後に本来のネットへ戻して
  ネック 3 本を再追加した。ジャンパのパッド配置・ネット・ネックは
  第2ラウンドの設計どおり維持されていることを座標で検証済み。
- 名前が空のフットプリント（SJ×4・J5・J6）は DSN の image 対応付け
  が壊れて配線が幻影位置へ行くため、書き出しコピーでのみ一意名
  （FP_<ref>）を付与した。
- JLEG キャステレーションパッドについて Freerouting が接続点を
  パッド外（基板外形の外）に取る問題への対策として、書き出し
  コピーにだけ基板左右端の配線禁止ストリップを追加した（最終基板
  には含まれない。最終基板に基板外形の外の配線・ビアが無いことは
  座標監査で確認済み）。
- Freerouting の 0.075mm ファンアウト線は取り込み後に 0.10mm へ
  一括拡大。残った局所干渉は手修正：USB_D-_C は A7 パッド内に
  ビア (9.28,1.22) を置いて In2 で合流、GP22 縦走路を +0.03mm
  東へ移動（GPIO4 とのクリアランス確保）、垂れたビア・スタブ
  （RESET／TB5）を除去。

## 実物照合が必要な近似箇所

- **裏面パッド GP17〜GP25（J6）の座標**：公開図面ベースの近似
  （前面パッド間のギャップ位置に 1.2×0.6mm パッド）。実物の裏面パッド
  位置とは一致しない可能性がある。使う前に実物と照合すること。
- ボタン・LED の位置は第2ラウンドで公式 STEP 実測値に合わせ済み
  （設計判断 11）。ただし LED の pin1 向きは実測できておらず従来維持。

## 実装（リフロー）について

- ペーストデータ： `gerber/ext_board-F_Paste.gtp` / `ext_board-B_Paste.gbp`
  （ステンシル発注にそのまま使える）。
- 配置図： `placement.png`。基板シルクにも参照番号を印刷済み。
- 両面実装：表面 = MDBT50Q・USB-C・ESD・LED・ボタン・0Ω、裏面 = LDO・
  コンデンサ×2・FFC×2・CC プルダウン×2。
- MDBT50Q はリフロー前提のモジュール。アンテナ端（基板下端側）に
  ハンダ・フラックス残渣が付かないよう注意。
