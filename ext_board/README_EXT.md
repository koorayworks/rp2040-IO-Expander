# ZERO-WIRELESS EXT REV.A — 延長基板（RP2040-Zero 互換フットプリント＋MDBT50Q）

分割キーボードの左右間通信を無線化するための延長基板。PC との接続は従来どおり
有線 USB（本基板は nRF52840 モジュール MDBT50Q を載せ、RP2040-Zero と同じ
キャステレーション足で既存基板に差し替えられる形にしたもの）。
仕様はリポジトリの `EXTENDED_SPEC.md`（凍結仕様）に準拠する。

- 基板外形： 18.0 × 43.5 mm（本物 23.5mm ＋ 延長 20mm）、厚さ 1.6mm、4層
- 発注データ： `gerber/`（銅4層・マスク・**ペースト（ステンシル用）表裏**・
  シルク・外形・Excellon ドリル・.gbrjob）
- 配置図： `placement.png`（上面／下面。手実装・リフローの参考用）
- ピン対応： `PINMAP_EXT.md`、部品表： `ext_board_bom.csv`（本書末尾にも転記）

## 前提（重要）

- **モジュールはブートローダ書き込み済みの MDBT50Q-1MV2（チップアンテナ版）を
  購入して搭載する想定**。書き込み済み品なら SWD 書き込みなしで USB/UART
  ブートローダ経由のファーム投入を想定する。SWD パッド（J5）は保険として残置。
- 電源は USB 給電のみ（EXTENDED_SPEC どおり昇圧・電源 mux は入れていない）。
  3.3V は LDO（TPS7A2033）で VBUS から生成。VSYS パッドには 0Ω（R3）経由で
  VBUS（5V 系）を従来どおり出す。
- ファーム側注意： MDBT50Q の **DCCH ピン（pin31）は NC**。ファームは
  **内部 LDO モード前提とし、DC-DC コンバータを有効化しないこと**
  （有効化すると動かない／不安定になる）。水晶ピン（P0.00/P0.01）と
  NFC ピン（P0.09/P0.10 系）も NC 扱い（詳細は PINMAP_EXT.md）。

## 設計判断

1. **MDBT50Q フットプリントの差し替え**：既存 CORE_BOARD のモジュール図は
   実ランドパターンではない抽象図形だったため使用せず、Raytac データシート
   推奨ランドパターンと全61パッド一致を検証した形状
   （出典： GitHub `siderakb/mdbt-micro` の `MDBT50Q.kicad_mod`）を採用。
   ピン番号⇔信号の対応はリポジトリの `MDBT50Q_PINMAP.csv` とデータシートで
   全ピン照合済み。
2. **上半分は機械マスター厳密維持**：23 キャステレーションパッドの座標・
   ネット、USB-C（TYPE-C-31-M-12）位置、BOOT/RESET ボタン位置は IO_BOARD
   からそのまま複製。裏面パッド GP17〜GP25＋GND（J6）は前面パッド間の
   ギャップ位置に配置。
3. **Rev.W の欠陥是正： USB-C の CC プルダウン追加**（R1/R2 = 5.1kΩ、
   CC1/CC2 → GND）。元の IO_BOARD には無く、C-to-C ケーブルで給電されない
   問題があったため新規追加した。裏面（B.Cu）配置。
4. **層構成**：4層。In1 = GND プレーン、F/B にも GND ポア＋スティッチ。
   In2 は信号層として使用（GND プレーン1枚構成は仕様の範囲内と判断）。
5. **設計ルール**：配線 0.10mm／クリアランス 0.10mm／ビア 0.40/0.20mm
   （JLCPCB 4層の標準製造範囲内）。hole clearance は 0.20mm、最小ドリル
   0.20mm に設定（キャステレーションとスティッチビアの密度のため）。
   `copper_edge_clearance` は重大度を warning に変更（キャステレーションと
   USB-C パッドの基板端接合は設計上必須のため。警告 34 件はすべてこの種）。
6. **アンテナキープアウト**：モジュールはアンテナ端を基板下端に向けて配置。
   全層銅箔禁止エリア x 4.35〜13.65 × y 38.0〜43.5mm をルールエリアで設定。
   当初案（x 3.0〜15.0）から M2 ネジ穴コートヤードとの干渉回避のため縮小した。
   チップアンテナ素子自体は完全に覆うが、**データシート推奨幅（約12.4mm）に
   対し本基板は約9.3mm と狭い**。電波到達距離に影響しうる点に留意
   （左右間通信の近距離用途を前提に許容した判断）。
7. **裏面部品とホスト側クリアランス**：LDO・入出力コンデンサ・FFC×2・
   CC プルダウンは裏面（B.Cu）に集中配置した。**本基板を載せるホスト基板側
   には裏面部品の高さぶんのクリアランス（切り欠き等）が必要**。FFC ケーブル
   は基板下方向（+Y）に出る。FFC#1 = トラックボール（TB1〜TB6）、
   FFC#2 = 拡張 GPIO 6 本（EX1〜EX6、新規割当て。PINMAP_EXT.md 参照）。
8. **VSYS 接続**：R3 = 0Ω で VBUS → VSYS を接続（従来どおり 5V 系を出す）。
   USB-C シェルは GND 接続。SBU ピンは無接続。
9. **M2 ネジ穴**：下端角 2 か所（中心 (1.8,41.2) / (16.2,41.2)、NPTH ⌀2.2）。
   基板幅 18mm に対し M2 ネジ頭（約 ⌀3.8〜4）が角に少しはみ出す。片持ちの
   固定補助として割り切ること。
10. **配線手法**：自作グリッド A* ルーター（tools/router.py）で自動配線し、
    USB は ESD（USBLC6-2SC6）経由でペアを短く配線。USB-C の信号パッド列は
    VBUS を後回しにし、先に D±/CC のスタブを通す順序で配線した
    （tools/gates3.py）。

  - 警告系： copper_edge_clearance 34（上記 5. の設計上のもの）、

- 未接続： 10 件（信号 6 ＋ GND ポア島 4。下記の残課題一覧）

## 残課題（未接続ネット一覧と理由）

修正ラウンドで GPIO3・TB4・GP17・GP21・GPIO28 を追加接続し、信号ネットは
57 中 51 まで接続した。残り 6 信号は下記の混雑箇所で経路が確保できなかった
もの。**いずれも機能必須ラインではない**（電源・USB・リセット・BOOT・
ステータス LED・FFC#1 の TB1〜TB6 全て・FFC#2 の EX1/EX2/EX4〜EX6 は
接続済み）。次リビジョンで直すなら「ブロッカーとなっている既配線の
引き直し」または「当該パッド周辺の部品微移動」が有効。

また、接続済みの GP17 と GPIO28 の経路には設計ルール（0.10mm）未満の
クリアランス箇所（clearance 17 件の大半）と、GP17×GPIO9／GPIO11、
GPIO6×TB3 の shorting_items 4 件、tracks_crossing 4 件が残っている。
発注前にこれらも解消すること。

| ネット | 未接続ペア | 理由 |
|---|---|---|
| GPIO6 | U1 pin25 側スタブ ⇔ JLEG パッド6 | スタブは pin25 北のスロット経由で In2 まで到達済み。残りの東向き長距離区間が中帯域の混雑（EX5/GPIO5/GP25 等）で確保できず |
| GPIO7 | U1 pin26 ⇔ JLEG パッド7 | U1 北列パッド群の密集ポケット。東西どちらの出口も隣接ネットのファンアウトで塞がれている |
| GPIO15 | JLEG パッド15 側 ⇔ U1 pin42 | 西〜南西の壁（TB4 の In2 階段＋GPIO26/27＋TB5/TB6 の南側チェーン）越えで確保できず。自動配線で一度接続したが南側ネットの経路確保のため引き剥がした |
| GPIO29 | JLEG パッド29 側スタブ ⇔ U1 pin45 | pin45 周辺のポケットが GPIO26/27・GPIO28 の経路で塞がれている |
| SWDCLK | J5 パッド3 側スタブ ⇔ U1 pin53 | 南西隅の密集（TB4/TB5/TB6/GPIO15/GPIO28 の経路が集中）。**ブートローダ書き込み済みモジュール前提では実害なし**。SWDIO は接続済み |
| EX3 | J4 パッド3 ⇔ U1 pin50 | J4 北側スロットは EX2 の南側付け替えで空けたが、pin50 周辺のポケットが TB4 南側チェーン等で塞がれている |
| GND | ポア島同士 ×4 | パッドを含まない孤立した GND ポア島（浮き銅）。実害はないが、気になる場合は該当島を削除するか次リビジョンでスティッチ追加を |

## 実物照合が必要な近似箇所

- **ステータス LED（D2, WS2812B-2020）の位置**：本物 RP2040-Zero の公開図面
  ベースの近似配置（(9.0, 9.4)）。実物と数 mm ズレる可能性がある。
- **裏面パッド GP17〜GP25（J6）の座標**：公開図面ベースの近似
  （前面パッド間のギャップ位置に 1.2×0.6mm パッド）。実物の裏面パッド
  位置とは一致しない可能性がある。使う前に実物と照合すること。

## 実装（リフロー）について

- ペーストデータ： `gerber/ext_board-F_Paste.gtp` / `ext_board-B_Paste.gbp`
  （ステンシル発注にそのまま使える）。
- 配置図： `placement.png`。基板シルクにも参照番号を印刷済み。
- 両面実装：表面 = MDBT50Q・USB-C・ESD・LED・ボタン・0Ω、裏面 = LDO・
  コンデンサ×2・FFC×2・CC プルダウン×2。
- MDBT50Q はリフロー前提のモジュール。アンテナ端（基板下端側）に
  ハンダ・フラックス残渣が付かないよう注意。
